Input Components (Value Sources)
Component	Description
Slider	A horizontal/vertical slider that outputs a value in a range (0-100, etc.)
Knob/Rotary	A circular dial you can rotate to set a value
Number Input	A text field where you type an exact number
Button	Momentary push button (ON only while held)
Keypad	Enter multi-digit numbers via keypad interface
Clock/Oscillator	Automatic ON/OFF pulses at configurable frequency
Stepper	Up/Down buttons to increment/decrement a value



Output Components (Value Display)
Component	Description
7-Segment Display	Classic digital number display (like a calculator)
Bar Graph/Meter	Visual bar that fills based on value (0-100%)
Gauge	Analog-style semicircular meter with needle
LED Array	Multiple LEDs that light up based on value (like volume bars)
Binary Display	Shows value as binary bits (e.g., 01011010)
Text/Label	Shows value with custom prefix/suffix text
Color Lamp	Light that changes color based on value (heatmap style)
Waveform/Scope	Shows history of values over time as a graph
Hex Display	Shows value in hexadecimal format
